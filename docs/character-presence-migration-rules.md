# Bloom 活人感迁移规则（当前阶段版）

更新时间：2026-04-03
适用阶段：Phase B / 基础 OOC 治理阶段
定位：旧 `setting` 中“不能丢的人味内容”迁入新角色结构的规则清单

边界说明：

- 这份文档只解决旧 `setting` 里“不能丢的人味内容”如何迁入新结构
- 不替代完整角色输入 contract
- 不直接定义场景读取矩阵、召回策略、本轮 snapshot 组装规则

---

## 1. 总目标

当前不是只做字段迁移，而是做“活人感迁移”。

用户原始输入全文必须保留。

迁移不是替代原文，而是在原文基础上提炼结构层。

也就是说，从旧 `setting` 迁到新结构时，不能只保住：

- 角色是什么性格
- 角色和用户是什么关系

还必须保住：

- 角色怎么说话
- 角色怎么偏爱用户
- 角色别扭、温柔、嘴硬、黏人、疏离时的质地
- 角色有哪些经典反应和表达习惯

本规则的目标不是恢复“旧 `setting` 全量直塞”，而是保证完整角色信息被保留、被识别、被分层消费。

也就是：

- 关键内容常驻
- 扩展内容按需召回
- 原文始终可回查和再提炼

---

## 2. 旧 setting 里最不能丢的内容

当前阶段，旧 `setting` 里最需要优先迁出的内容分为五类。

### 2.1 角色对用户的态度

包括：

- 基础亲疏
- 主动 / 被动倾向
- 偏爱方式
- 占有欲、保护欲、依赖感、克制感

迁入目标：

- 主体进入 `Core Persona`
- 明显的关系表达风格进入 `Expression Style`

### 2.2 表达质地

包括：

- 说话节奏
- 语气松紧
- 句子长短
- 锋利、温吞、懒散、克制、黏人、戏谑的表达手感

迁入目标：

- 主体进入 `Expression Style`

### 2.3 经典反应模式

包括：

- 被夸时怎么反应
- 被试探时怎么反应
- 吃醋时怎么反应
- 亲密时怎么反应
- 生气、嘴硬、心软时怎么转折

迁入目标：

- 主体进入 `Expression Style`
- 涉及刚性不可越线内容时补入 `Boundary Pack`

### 2.4 边界与禁忌

包括：

- 明确不能说的话
- 明确不能越过的关系边界
- 不允许编造的经历或记忆
- 角色原则和不可违背点

迁入目标：

- 全部优先进入 `Boundary Pack`

### 2.5 背景与设定补充

包括：

- 身份背景
- 成长经历
- 世界观绑定
- 长设定说明

迁入目标：

- 主体进入 `Extended Lore`
- 如果其中有稳定影响表达方式的部分，可提炼一句进入 `Core Persona`

---

## 3. 迁入规则

### 3.1 Core Persona 收什么

只收稳定、常驻、必须高优先级保留的内容。

当前阶段建议收：

- 核心性格
- 对用户的基础关系姿态
- 角色核心气质
- 关键关系边界

不应塞入：

- 大段背景故事
- 过多场景化细节
- 大量具体台词示例

### 3.2 Expression Style 收什么

这是当前阶段补“人味”的核心层。

当前阶段建议收：

- 说话节奏
- 语气松紧
- 别扭 / 温柔 / 嘴硬 / 黏人等比例
- 常见反应方式
- 小动作和典型表达习惯

要求：

- 不能只写成几个空泛形容词
- 要尽量写成“怎么表现出来”
- 必须优先写“表现方式”，不要只写“性格判断”

例如不要只写：

- 温柔
- 嘴硬
- 黏人

而要写成：

- 温柔时怎么落句
- 嘴硬时怎么转折
- 黏人时怎么靠近
- 克制时怎么收着表达

### 3.3 Boundary Pack 收什么

当前阶段建议收：

- 不能突破的亲密边界
- 不能编造的关系事实
- 不允许违背的角色原则
- 高风险 OOC 点

要求：

- 优先级高于 `Extended Lore`
- 不允许被 `User Mask`、`Memory` 或 `sceneHints` 覆盖

### 3.4 Extended Lore 收什么

当前阶段建议收：

- 背景经历
- 设定补充
- 世界观与前史
- 复杂关系上下文

要求：

- 默认不全量常驻
- 需要按场景读取

---

## 4. 当前阶段迁移优先级

当前阶段迁移优先级从高到低为：

1. `Boundary Pack`
2. `Core Persona`
3. `Expression Style`
4. `Extended Lore`

原因：

- 边界最不能错
- 核心人格必须稳
- 人味必须保
- 背景可以后召回

---

## 5. 当前阶段的迁移判断标准

从旧 `setting` 迁到新结构后，至少要满足下面四条：

1. 角色的基础态度不能变
2. 角色的说话味道不能明显变薄
3. 角色对用户的偏爱方式不能消失
4. 角色的禁忌和边界不能丢

如果迁完后只剩下：

- 性格标签
- 简短关系说明
- 几句概括性描述

但角色说起话来明显变成“标准温柔陪伴 AI”，就说明迁移失败。

迁移失败的典型表现：

- 回复变成通用温柔陪伴口吻
- 角色态度保留了，但说话手感消失
- 关系说明还在，但偏爱方式不见了
- 不再像“这个角色”，而像“一个设定差不多的 AI”

---

## 6. 当前阶段不做的事

1. 不做复杂自动人格解析器
2. 不做重型召回系统
3. 不做一口气重写全部场景
4. 不做“所有旧设定一键完美拆层”的承诺

当前阶段只做：

- 先定义迁移规则
- 先保住最不能丢的人味
- 先保证主链不继续把角色削薄

---

## 7. 和 UI 的关系

当前阶段允许用户继续用大框输入。

系统依据本规则做迁移和识别。

后续轻量分层 UI 也应以本规则为基础，而不是绕开这套迁移规则另起一套输入语义。

---

## 8. 当前阶段的通俗意思

这一步不是把旧设定“搬个位置”而已。

而是要分清楚：

- 哪些内容是在说“这个人是谁”
- 哪些内容是在说“这个人说话是什么味道”
- 哪些内容是在说“这个人不能越什么线”
- 哪些内容只是背景资料

这样迁完之后，角色才不会只剩骨架，还能保住原来的手感。
