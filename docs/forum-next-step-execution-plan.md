# 论坛近期实施方案（对齐版）

## 1. 文档目的

这份文档用于把当前论坛需求重新对齐成一份可以直接执行的近期方案。

它不再只回答“论坛还缺什么”，而是明确回答下面 4 个问题：

1. 论坛当前真实卡在哪
2. 这轮最该先做什么
3. 众生 / 镜间 / 开楼 / 设置页的边界到底是什么
4. 每一阶段做完之后怎么验收

这份文档应视为论坛近期默认执行稿。

---

## 2. 当前阶段重新判断

### 2.1 当前真实状态

论坛已经不是空页面，也不是只能发几段 AI 文本的阶段。

现在已经具备：

- 主 App 内论坛入口
- 静态种子帖开局
- 公共频道结构
- 镜间基础入口
- 用户发帖
- 用户评论
- 发帖后自动出现首轮互动
- 评论后自动补后续互动
- 扁平评论区
- 动态作者持久化
- 热帖 / 趋势榜基础逻辑

### 2.2 当前真正的问题

当前论坛最主要的问题已经不是“有没有功能”，而是下面 5 类：

1. 刷新生成失衡
   - 特殊帖太多
   - 普通帖太少
   - 整页太用力

2. 新网友太少
   - 熟脸复用偏强
   - 刷新后新面孔不足

3. 生成控制缺失
   - 当前右上角还是“筛选”
   - 用户不能真正控制“这轮要开什么帖子”

4. 众生 / 镜间虽然前台分开，但底层生成规则还没完全分开

5. 设置层几乎没有
   - 论坛设置页不存在
   - 世界书读取无法由用户细调

### 2.3 当前最正确的动作

当前最正确的动作不是先补记忆回流，也不是先继续堆 prompt 规则，而是：

**先把“开楼系统 + 生成控制 + 众生 / 镜间主题分流 + 设置页骨架”做实。**

---

## 3. 本轮总目标

本轮的目标不是先把论坛写得更会说话，而是先把主题功能跑通。

### 3.1 本轮目标

1. 把“筛选”改成真正的“开楼”
2. 支持一次生成 10 个帖子
3. 让区域和帖型都变成生成输入，而不是浏览过滤
4. 把普通帖重新拉回主底盘
5. 把新网友重新拉回主力
6. 把众生和镜间的主题生成逻辑真正分开
7. 把论坛设置页骨架搭起来，为世界书设置留入口

### 3.2 本轮不优先做

下面这些明确不插队：

- forum memory write-back
- 聊天引用论坛经历
- 完整匿名追踪系统
- 投票完整持久化闭环
- prompt 终版精修

原因：

如果“开什么楼、开多少、谁来发、在哪开、怎么控”都还没收稳，后面任何系统深化都会建立在松地基上。

---

## 4. 众生 / 镜间重新定义

这部分必须写死，后续所有实现都不能偏。

### 4.1 众生

众生是公共论坛主区。

它的核心要求：

- 是公共世界论坛
- 聊各种各样的内容
- 不围着用户和角色单独打转
- 普通帖是底盘
- 各频道保留自己的世界感

众生应该更像：

- 有人顺手吐槽
- 有人轻八卦
- 有人求助
- 有人记录
- 有人目击
- 有人开盘

但它首先必须像一个“公共区”。

### 4.2 镜间

镜间不是普通公共区的变体，它是：

**角色和用户的主区。**

镜间的核心要求：

- 讨论对象以角色和用户为中心
- 重点围绕关系、例外、护短、目击、代餐、围观展开
- 是“别人眼里的角色”和“别人眼里的你们”
- 允许角色本人在这里留下痕迹

镜间应该更像：

- 关系观察楼
- 角色目击楼
- 同人代餐楼
- 危险魅力楼
- 投票站队楼

### 4.3 验收标准

- 众生里不应整页都围着用户和角色转
- 镜间里则应明显围绕角色和用户展开
- 用户应能一眼分出“公共论坛”和“关系围观区”不是一个东西

---

## 5. Phase A：开楼系统

这是当前第一优先级。

### 5.1 入口改造

首页右上角：

- `筛选` 改为 `开楼`

这个弹层不再是“筛出已有帖子”，而是：

**决定这一轮要生成什么帖子。**

### 5.2 开楼模式

开楼分成两个模式：

#### 模式 A：随机开楼

- 一次固定生成 `10` 帖
- 区域支持多选
- 帖型支持多选
- 如果用户没有特殊限制：
  - 普通帖至少占一半
  - 其他帖型在剩余配额里随机分布
- 投票帖、片段帖、同题帖不是每轮强制保底

#### 模式 B：按设置开楼

- 一次固定生成 `10` 帖
- 区域支持多选
- 帖型支持多选
- 用户选什么，就开什么
- 后续可扩展为按比例生成
- 第一版至少做到：
  - 只从用户选中的区域里生成
  - 只从用户选中的帖型里生成

### 5.3 区域与帖型规则

当前 UI 上的区域和帖型选择，后续不再只是前台过滤。

它们必须变成：

- 区域多选 = 本轮生成区域池
- 帖型多选 = 本轮生成帖型池

生成逻辑要先看用户选中的池，再去出帖。

### 5.4 随机开楼默认配方

这是当前默认规则：

- 每次生成 `10` 帖
- 普通帖至少 `5` 帖
- 剩余 5 帖由其他帖型分配
- 不再强制一轮覆盖过多特殊帖
- 整页不应看起来全是发酵帖 / 反转帖 / 片段帖

### 5.5 普通帖定义

普通帖不是空白帖，也不是弱化版特殊帖。

普通帖现在的定义是：

- 聊各种各样的内容
- 作为论坛主底盘存在
- 不要求每条都强剧情
- 不要求每条都高戏剧性
- 能承担日常、吐槽、观察、轻八卦、轻求助、世界区日常

### 5.6 新网友与熟脸比例

本轮明确采用下面这套规则：

- 新网友：`80%`
- 熟脸：`20%`

熟脸来源规则：

- 如果用户有关注的网友：优先从关注列表里回流 `1-2` 个
- 如果用户没有关注的网友：从已生成过的网友里回流 `1-2` 个
- 熟脸不能再压住整页

### 5.7 热帖要求

热帖继续按趋势榜那套逻辑走。

这轮不重做热帖系统，只要求：

- 开楼生成结果不要人为制造整页热帖感
- 首页热感和趋势榜逻辑继续保持同源

### 5.8 片段帖要求

片段帖前台不再直接叫“片段帖”。

它的展示要求改成：

- 更像“同人文”或“短打帖”
- 要有自己的标题
- 仍然属于特殊帖型，但不要前台硬露一个过于机械的“片段”标签

### 5.9 投票帖要求

投票帖本轮规则：

- 随机模式下按概率出现
- 按设置模式下用户选了才生成
- 不做固定保底
- 不优先做完整投票闭环

### 5.10 本阶段验收

- 首页右上角不再是筛选，而是开楼
- 用户能明显理解“随机开楼”和“按设置开楼”的区别
- 一次调用能稳定开出 10 帖
- 普通帖占比明显回升
- 新网友明显比熟脸多
- 区域和帖型的多选不再只是前台筛选假动作

---

## 6. Phase B：众生 / 镜间主题分流

开楼系统跑通后，马上进入这一阶段。

### 6.1 众生生成规则

众生开楼要满足：

- 主题散
- 公共区感强
- 聊各种内容
- 普通帖为主
- 世界区日常可见
- 不以用户和角色为唯一中心

### 6.2 镜间生成规则

镜间开楼要满足：

- 帖子围绕角色和用户
- 关系观察、目击、代餐、危险魅力、站队更自然
- 更像围观关系区
- 不是公共区帖子简单换皮复制

### 6.3 底层要求

这一阶段必须把“前台分板”和“底层分流”对齐：

- 镜间单独生成主题池
- 镜间单独作者池逻辑
- 镜间回帖不再退回公共频道语义
- 公共区复用规则和镜间复用规则分开

### 6.4 本阶段验收

- 众生和镜间刷出来的贴子，用户一眼能感到主题不同
- 镜间不再像公共区的 junction 变体
- 镜间的帖子明确在围绕角色和用户长

---

## 7. Phase C：论坛设置页

这一阶段把图三的“编辑个人资料”升级成真正的论坛设置入口。

### 7.1 设置页结构

论坛设置页建议拆成 3 组：

1. 资料设置
2. 生成设置
3. 世界书设置

### 7.2 资料设置

保留当前内容：

- 头像
- 昵称
- 简介

### 7.3 生成设置

新增：

- 默认开楼模式
  - 随机
  - 按设置

- 默认一次生成数量
  - 当前固定 10

- 默认普通帖占比
- 默认新网友占比
- 默认熟脸回流数量
- 默认允许帖型
- 默认允许区域
- 众生默认配方
- 镜间默认配方

### 7.4 世界书设置

世界书这一轮不强行接满内容，但要先把设置层搭起来。

至少包括：

- 世界书总开关
- 引用强度
- 引用范围
- 分类读取
- 哪些链路允许使用世界书
  - 普通新帖
  - 镜间开楼
  - 热帖后续
  - AI 回帖
  - 角色帖

### 7.5 本阶段验收

- 图三不再只是改资料
- 用户可以明确找到论坛生成控制入口
- 世界书设置不再是隐式逻辑，而是论坛设置的一部分

---

## 8. Phase D：内容和 prompt 收口

这一步明确后置。

等前面三阶段跑通后，再集中收：

- 普通帖太人机的问题
- prompt 太说明书的问题
- 评论区功能位感太强的问题
- 片段帖质感问题
- 镜间围观语感问题

### 本阶段重点

- 少一点“模型感”
- 多一点“论坛现场感”
- 普通帖变回主底盘，但不无聊

---

## 9. 当前文档与旧方案的关系

旧论坛总方案主线不变：

1. 公共论坛先成立
2. 论坛先变好玩
3. 围观 / 镜间模式强化
4. 身份系统补齐
5. 记忆回流最后接

本次调整的是近期执行顺序：

从原本偏“活人感细节收口”，调整为：

**先把开楼系统、生成控制、众生 / 镜间主题分流和论坛设置页骨架做实。**

---

## 10. 近期默认开发顺序

### Step 1

先做开楼系统：

- 筛选改开楼
- 随机 / 按设置双模式
- 一次 10 帖
- 普通帖保底一半
- 新网友保底 80%

### Step 2

再做众生 / 镜间真正分流：

- 众生公共区
- 镜间关系主区
- 主题池分开
- 作者池逻辑分开

### Step 3

再做论坛设置页：

- 资料设置
- 生成设置
- 世界书设置

### Step 4

最后再集中收内容：

- 普通帖自然度
- 新网友活人感
- 评论区减模板感
- 片段帖标题和展示优化

---

## 11. 当前最终执行结论

论坛当前最该做的，不是继续往 prompt 上堆规则，也不是先接记忆系统，而是：

**先把“开楼”做成真正的主题功能入口，把一次生成 10 帖、普通帖保底、新网友保底、众生 / 镜间主题分流和论坛设置骨架跑通。**

这份文档当前应视为论坛近期默认实施方案。
