# 聊天图片识别边界与手测清单

更新时间：2026-04-08

## P6 失败边界

当前图片主链已经接通，但下面这些情况仍可能不稳定：

1. 超糊图片
图片主体太小、太糊、压缩太重时，模型可能只能看出大概情绪，看不清具体细节。

2. 纯梗图
梗图高度依赖网络语境时，模型可能能看出情绪，但接不准梗本身。

3. 动图首帧偏差
当前会把图片转成静态可读格式，动图更像“看一帧”，不保证完整理解动图过程。

4. 远程图片失效
如果外链图片地址过期、限流、拒绝抓取，模型就拿不到图。

5. 图上字太小
带字表情包如果字很小、叠色严重、描边太复杂，读字可能不稳。

6. 多主体图片
一张图里信息太多时，模型可能抓到主情绪，但忽略你更在意的局部。

7. 截图类图片
复杂聊天截图、长图、UI 截图可能能读到部分字，但不保证完整逐行理解。

## P7 固定手测清单

每次改完图片链路后，固定测下面 7 组：

1. 带字表情包
示例：`求放过`、`别骂了`、`你说得对`
目标：能接住图中文字，不只说“你发表情了”。

2. 无字情绪表情包
示例：哭哭、委屈、生气、无语、撒娇
目标：能接住图里情绪和态度。

3. 普通人物图片
示例：自拍、他拍、卡通头像
目标：能知道大概是人像，不把它当普通附件。

4. 普通场景图片
示例：海边、街道、房间、食物
目标：能知道图片主题，不只泛泛提图。

5. 截图图片
示例：聊天截图、报错截图、界面截图
目标：能知道是截图，并尽量抓住主要内容。

6. 远程链接图片
示例：`https://...`
目标：确认外链图也能正常进入模型，不因格式或链接问题直接报错。

7. 动图/特殊格式图片
示例：`gif`、`webp`
目标：确认不再出现格式报错，至少能给出合理近似理解。

## 通过标准

1. 不出现格式报错
2. 不出现乱码
3. 不再频繁回复“你又发表情了”“你发了张图”
4. 回复明显比过去更贴近图中文字或图情绪
